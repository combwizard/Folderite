Folderite

A middle-click folder menu for Windows

Middle-click in Explorer or any Open/Save dialog and a menu of your folders opens at the cursor: favorites, folders open in other windows, recent ones and the one on the clipboard. Pick one and that window goes there.

Features

Your folders, one click away

01

A folder menu at the cursor

Middle-click in an Explorer window and the menu opens right at the cursor. It lists your favorites, the folders open in your other windows, your recent folders and a folder path you copied. Pick one and the window you clicked goes there.

Windows 11 tabs work too: the active tab navigates, and middle-clicking a tab still closes it.

02

Open and Save dialogs

Any app that uses the standard Windows file dialog gets the same menu: Notepad, Office, your browser. The dialog jumps to the folder you pick, and the file name you already typed stays put.

In folder pickers, picking a folder navigates there. It doesn't accept the folder for you.

03

Recent folders, ranked by use

Folderite notes the folders you visit in any supported file manager and ranks them by how often and how recently you went there, the way zoxide does. Your everyday folders rise to the top of Recent without you curating anything.

Keep folders out with patterns like C:\Windows\* or *\node_modules\* under Settings › Exclusions. Remove entries or clear the list under Settings › History.

04

A settings window

In Settings you drag favorites to reorder them or nest them in groups, drop folders in from Explorer, add your own actions next to the built-in Open terminal here, and choose which sections the menu shows. Changes apply as soon as you make them, and Preview menu shows you the real menu.

Rather edit text? It's all in one config.json. Move it next to the exe and Folderite becomes portable.

Supported apps

Where it works

Everywhere else, middle-click works as usual.

  • Windows Explorer

    Navigates the window you clicked, or its active tab on Windows 11.

  • Open & Save dialogs

    The standard Windows file dialogs and folder pickers, in any app. Your typed file name is kept.

  • Directory Opus

    In a dual-pane lister, the side you clicked navigates.

  • Total Commander

    Changes the folder of the panel you clicked, left or right. Newer and less tested.

  • XYplorer

    Jumps with XYplorer's own ::goto command. Newer and less tested.

  • Blender

    The File View window: Open, Import and folder pickers. Your clipboard is put back afterwards.

  • The desktop

    Middle-click the desktop and the folder you pick opens in a new Explorer window.

  • The tray icon

    Left-click it for your folders from anywhere: favorites, open windows, recent and clipboard. Your pick opens in a new Explorer window.

Install

Getting started

  1. Get the .NET 10 Desktop Runtime

    Install the .NET 10 Desktop Runtime (x64) from Microsoft if you don't have it yet.

  2. Download and unzip

    Grab Folderite-<version>-win-x64.zip from the latest release and unzip it to any folder you like.

  3. Run Folderite.exe

    It sits in the tray. Right-click the icon for Settings, Pause and Start with Windows, then middle-click in a folder window.

To upgrade, quit Folderite from the tray and unzip the new release over the old folder. Your settings are kept. Needs Windows 10 1903 or later; Windows 11 recommended.

FAQ

Common questions

Does middle-click still work in my other apps?

Yes. Folderite only takes over the middle click when it lands on a window it supports. In your browser, editor or anywhere else, middle-click works as it always has. In Windows 11 Explorer, middle-clicking a tab still closes it.

Can I turn it off for a while, or for one app?

Choose Pause in the tray menu to turn it off until you resume. To leave one app alone for good, add it under Settings › Exclusions (disabledProcesses in the config).

Where are my settings stored?

In %APPDATA%\Folderite\config.json, next to history.json. Settings › General › Change location… moves both to another folder.

Pick Folderite's own folder and it becomes portable: a config.json next to the exe always wins, so your settings go wherever the folder goes.

Does Folderite connect to the internet?

No. There's no telemetry and no update check. Your folder history stays in history.json on your PC.

Windows says it “protected my PC”. Is that expected?

It can be. The exe isn't code-signed, so SmartScreen may warn about it the first time it runs. Click More info, then Run anyway. The release zip is built from the public source by GitHub Actions, and you can always build it yourself.

Why do I need the .NET Desktop Runtime?

Folderite is a .NET 10 app, and the release relies on the shared runtime instead of bundling its own copy. That keeps the download small, and other .NET apps on your PC use the same runtime.

How does it work in Blender?

Blender gives other programs no way to set the folder of its File View, so Folderite types the path into the path field for you, pasting it through the clipboard. Your clipboard, text or image, is put back afterwards. Blender also doesn't say which folder it's showing, so the menu has no current-folder entry there.

How do I uninstall it?

Turn off Start with Windows in the tray menu, choose Exit, and delete the Folderite folder. To remove your settings as well, delete %APPDATA%\Folderite (or the folder you moved them to). If you moved them, Folderite also remembered that location in the registry key HKCU\Software\Folderite, which you can delete too.

Is it free?

Yes. Folderite is open source under the MIT license. Bug reports and ideas are welcome on GitHub Issues.
